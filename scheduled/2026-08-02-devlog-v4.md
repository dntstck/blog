# devlog v4 - nightly rsync automation to Vostro A100 Gogs server

## overview

created a nightly automation job to sync `~/dev/scripts` to the gogs server running on the vostro a100. 
ensures projects, codes, docs & scripts remain backed up and versioned without manual commits.

## hardware

- **server:** vostro a100
- **role:** gogs git server 
- **OS:** debian
- **network:** 1gb ethernet

## rsync script

```bash
#!/bin/bash
rsync -av --ignore-existing ~/dev/scripts/ sysadmin@vostro-a100:/home/sysadmin/gogs-repos/scripts/
```

## cron job

```bash
crontab -e
0 3 * * * /home/sysadmin/rsync-scripts.sh
```

## validation

```bash
ssh sysadmin@vostro-a100 "ls -R gogs-repos/scripts"
git status
```

## results

- nightly sync runs cleanly 
- no duplicate pushes 
- no missed updates 
- projects, code, docs & scripts preserved 
- gogs repo stays up‑to‑date automatically
