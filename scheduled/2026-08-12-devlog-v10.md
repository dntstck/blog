# devlog v10 - setting up smtp & email notfications on mainframe node

i am currently starting my implementation of a living system on my mainframe,
using alpine vms, scripts, microservices etc to ensure a fully intertwined and symbotic collection of systems.

## email notifications using smtp and gmail

easiest option is to use gmail. linux internal mail is pretty difficult to set up to work across nodes.
using gmail means outbound email is extremely easy to use, plus there is little point with internal mail;
i would have to be directly connected to the mainframe/a server node to see any notifications,
it would be more sensible to have them sent to my phone.

## smtp setup

for emails, i will be using just the overseer node (vServer-overseer). this node is perfect for this as it watches all the other servers;
it oversees them. hence the name. i can also ensure any notifications are routed directly to this node then sent out via email.

```bash
apk add msmtp msmtp-mta mailx
```

![installing smtp via apk](assets/img/devlog-smtp-apk.png)

now to create config for msmtp: `/etc/msmtprc`

```bash
defaults
auth           on
tls            on
tls_trust_file /etc/ssl/certs/ca-certificates.crt
logfile        /var/log/homelab/msmtp.log

account gmail
host smtp.gmail.com
port 587
from OUTBOUND-EMAIL-HERE
user RECEPIENT-EMAIL-HERE
password GOOGLE-APP-PASSWORD-HERE

account default : gmail
```

finally, ensures sendmail uses msmtp:

```bash
sudo ln -sf /usr/bin/msmtp /usr/bin/sendmail
```
