## gogs

gogs is a git server, written entirely in go. extremely fast and runs well on older hardware. setup and use is an absolute breeze.

after creating a repo in the web ui, i can simply add an existing repo (or create a new one) by adding a pre existing dir :

`cd /test && git init`

or create a new repo entirely:

`mkdir test && cd test && touch README.md && git init`

with git initalised, i can add the new files, commit, add remote and push :

```bash
git add .
git commit -m "first commit"
git remote add origin http://192.168.10.164:3000/sysadmin/test.git
git push -u origin master
```

thats it, repo added and pushed.

## on &&

you may have noticed the use of `&&` in my commands, i am always stringing commands together using these operators, it makes life easier. 
they only fire if the previous command succeeds, with the last successful command executed being the final command that runs.
there are others, such as `||` and `&|`, but i have got by just fine with `&&`.
