## devlog – fixing the scheduled posts pipeline

- scheduled posts weren’t deploying, jekyll kept building the wrong commit
- schedule workflow pushed the moved post, but jekyll ignored the sha and rebuilt `master` head
- root cause: github actions drops dispatch refs unless the workflow defines inputs
- dispatch `"ref"` was silently ignored; checkout fell back to `github.ref`
- added `workflow_dispatch.inputs.ref` to jekyll.yml
- updated checkout to use `github.event.inputs.ref || github.ref`
- schedule workflow now dispatches the sha into the input
- verified via jekyll logs: jekyll built the correct commit `8da364c9…`
- pipeline now stable, scheduled posts publish automatically

## what broke

my jekyll.yml workflow originally had:

```yaml
on:	
	push:
		branches: ["master"]
	workflow_dispatch:

jobs:
	build:
		steps:
		- name: Checkout
		uses: actions/checkout@v4
		with:
			ref: ${{ github.event.workflow_dispatch.ref }}
```

problem:

- `github.event.workflow_dispatch.ref` is null when triggered by a push
- schedule workflow pushes > jekyll runs via push > checkout gets `ref: null`
- checkout falls back to default branch > builds old commit
- site only updates after a manual push

jekyll logs showed:

```
Checking out the ref
/usr/bin/git log -1 --format=%H
d824d7e4cb700e54f46167650e24145021e214cf
```

this sha was not the commit created by the scheduling script.

## what i tried (failed)

1. forcing checkout to master

```yaml
with:
	ref: master
```

but jekyll always built master HEAD, ignoring the dispatched sha.

2. using workflow_dispatch.ref directly

```yaml
with:
	ref: ${{ github.event.workflow_dispatch.ref }}
```

but this only works for manual dispatch & fails for push triggers as the ref is null.

3. sending the sha directly in dispatch

schedule.yml:

```bash
-d "{\"ref\":\"$COMMIT_sha\"}"
```

result:
github ignored `"ref"` because the workflow had no inputs defined.

## what fixed it

1. define an input for the ref

```yaml
on:
	push:
		branches: ["master"]
	workflow_dispatch:
		inputs:
			ref:
			description: "Commit sha to build"
			required: false
			default: "master"
```

2. update checkout to use the input

```yaml
with:
ref: ${{ github.event.inputs.ref || github.ref }}
```

now:

- dispatch > uses `github.event.inputs.ref`
- push > uses `github.ref` (refs/heads/master)

3. update schedule.yml dispatch payload

```bash
-d "{\"ref\":\"$COMMIT_sha\"}"
```

now github maps `"ref"` > `github.event.inputs.ref`.

## final working jekyll.yml

```yaml
on:
	push:
		branches: ["master"]
	workflow_dispatch:
		inputs:
			ref:
			description: "Commit sha to build"
			required: false
			default: "master"

jobs:
	build:
		steps:
		- name: Checkout
		uses: actions/checkout@v4
		with:
		ref: ${{ github.event.inputs.ref || github.ref }}
```

## final working schedule.yml dispatch

```bash
COMMIT_sha=$(git rev-parse HEAD)
curl -X POST \
-H "Accept: application/vnd.github+json" \
-H "Authorization: Bearer ${{ secrets.GITHUB_TOKEN }}" \
https://api.github.com/repos/${{ github.repository }}/actions/workflows/jekyll.yml/dispatches \
-d "{\"ref\":\"$COMMIT_sha\"}"
```
