# devlog-v6; configuring the terminal with zsh, ohmyzsh and p10k

![oh my zsh](devlog-ohmyzsh.png)

fresh reinstall of debian requires a few tweaks for my own visual preferences, a different shell & theme.
this involves zsh, ohmyzsh & powerlevel10k, a blazing fast shell, layered with ohmyzsh's customization and
p10k's themes.

## install zsh

the system needs zsh before oh my zsh:

```bash
sudo apt update && sudo apt install zsh
```

- verify install: zsh --version
- switch default shell: chsh -s $(which zsh)
- log out & back in

![zsh version](devlog-zsh-version.png)

## install ohmyzsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

## powerlevel10k

```bash
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
```

now open ~/.zshrc

```bash
sudo vim ~/.zshrc
```

set the theme:

```bash
 ZSH_THEME="powerlevel10k/powerlevel10k"
```
![p10k change theme](devlog-zshrc-p10k.png)


save & reload: 

```bash
source ~/.zshrc
```

configure:

![p10k change theme](devlog-p10k-configure.png)

- set theme to rainbow
- ascii mode
- fluent
- many icons

![p10k post configure](assets/img/devlog-chsh.png)
