# devlog v8 - ssh keys

re-adding ssh keys to github after a fresh distro install on a development machine.

## gen new key

`ssh-keygen -t ed25519 -C "<node-name>"`

replace <node-name> with the name of the machine.

press enter twice and the key is stored in :

```bash
~/.ssh/id_ed25519
~/.ssh/id_ed25519.pub
```

now, for the public key:

`cat ~/.ssh/id_ed25519.pub`


copy the entire thing and either add it to github by going to settings > ssh and gpg keys,
or add to local git server by:

ssh into local git server:
`ssh admin@gitserver`

open your auth keys:
`vim ~/.ssh/authorized_keys`

paste in the key at the bottom, save & exit:
`:wq!`

 done.
