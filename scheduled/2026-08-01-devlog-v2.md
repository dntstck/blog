# setting up rust

fresh install of debian requires a fresh rust install.

## install rust using rustup

install prereqs:

```bash
sudo apt install build-essential pkg-config libssl-dev
```

now rust itself:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

pick 1 when asked. then reload shell with:

```bash
source ~/.cargo/env
```

verify install:

```bash
rustc --version
cargo --version
```

update:

```bash
rustup update
```

### adding common targets for cross compilation

riscv:

```bash
rustup target add riscv64gc-unknown-linux-gnu
```

arm:

```bash
rustup target add aarch64-unknown-linux-gnu
rustup target add armv7-unknown-linux-gnueabihf
```

installing clippy (essential!):

```bash
rustup component add clippy
```

now verify it installed correctly:

```bash
cargo clippy --version
```

clippy can now be used to lint projects:

```bash
cargo clippy
```

or with a very strict lint, if you enjoy pain:

```
cargo clippy -- -W clippy::all
```

creating a test project:

```bash
cargo new testproj
cd testproj
cargo run
```

test build:

```bash
cargo build --release
```

done.
