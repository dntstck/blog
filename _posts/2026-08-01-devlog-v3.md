# devlog v3 - rv2 microcluster, full pmix + openmpi rebuild

## overview

Performed a full clean rebuild of pmix & openmpi on the rv3 microcluster to maintain reproducibility for hpc workflows. 
all work/access  is done directly on `riscv-core` (192.168.0.64), which is the control node, with validation across `riscv-node-1` (192.168.0.65) & `riscv-node-2` (192.168.0.66).

## nodes

- riscv-core — 8gb ram, dual nvme (2×128gb)
- riscv-node-1 — 8gb ram, single nvme (128gb)
- riscv-node-2 — 8gb ram, single nvme (128gb)
- network: dual gb ethernet per node
- os: risc-v ubuntu server
- scheduler: slurm
- mpi stack: pmix + openmpi

## commands used

```bash
# remove old pmix/openmpi
sudo rm -rf /usr/local/pmix /usr/local/openmpi

# clone pmix
git clone https://github.com/openpmix/openpmix.git
cd openpmix
./autogen.pl
./configure --prefix=/usr/local/pmix
make -j4
sudo make install

# rebuild openmpi against new pmix
git clone https://github.com/open-mpi/ompi.git
cd ompi
./autogen.pl
./configure --prefix=/usr/local/openmpi --with-pmix=/usr/local/pmix
make -j4
sudo make install
```

## validation

```bash
mpirun --version
srun -N3 hostname
mpirun -np 6 -host riscv-core,riscv-node-1,riscv-node-2 ./hello_world
```

## results

- pmix rebuilt cleanly
- openmpi linked correctly
- slurm launches multi‑node mpi jobs without issue
- all three rv3 nodes participate correctly
- cluster remains clean & maintained for hpc portfolio work
